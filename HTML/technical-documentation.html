C Documentation

Introduction Variables Conditionals Loops Functions
Introduction

C is a general-purpose, procedural programming language that gives programmers low-level access to memory and system resources.

Variables

Variables store data that can be used and manipulated throughout a program. Every variable in C has a type.

int age = 25; float price = 9.99; char grade = 'A';
Conditionals

Conditionals let a program make decisions using if, else if, and else statements.

if (n > 0) { printf("Positive\n"); } else { printf("Not positive\n"); }
Loops

Loops let a program repeat a block of code, using for, while, or do-while statements.

for (int i = 1; i <= n; i++) { printf("%d ", i); }
Functions

Functions group reusable blocks of code that can accept parameters and return values.

int add(int a, int b) { return a + b; }
